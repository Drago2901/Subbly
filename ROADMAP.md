# Subbly Roadmap

## Phase 1 — Export Reliability
- Export state machine
- Deterministic MediaRecorder finalization
- FFmpeg lifecycle and cleanup
- Cancellation and recovery
- WebM fallback
- Repeat-export protection
- Export regression tests

## Phase 2 — Editor Core
- Timeline foundation
- Caption editing and timing controls
- Snapping and alignment guides
- Undo/redo history hardening
- Keyboard shortcuts
- Multi-select
- Copy/paste/duplicate
- Shared preview/export rendering rules
- Responsive editor layout

## Phase 3 — Creator Engine
- Caption presets
- Animation presets
- Templates
- Stickers/GIFs
- Music and SFX
- B-roll
- Transitions

## Phase 4 — AI Creator
- Automatic captions
- AI caption styling
- Highlight detection
- Hook/title suggestions
- B-roll suggestions
- One-click Short generation

## Current Focus
Phase 2 — Editor Core. The goal is to make editing fast, predictable, and scalable before adding more creator features.
